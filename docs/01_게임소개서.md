## 1. 한 줄 소개

**Director Loop**는 Left 4 Dead식 긴장-이완 페이싱과, Slay the Spire식 선택, Elden Ring식 읽히는 전투를 7분 런에 압축한 게임입니다.  
핵심은 “AI를 써서 콘텐츠를 만들었다”가 아니라, **AI Director가 플레이를 관찰하고 개입하며, 그 이유를 Why UI에 남긴다**는 점입니다.

---

## 2. 기획 의도

NAN(Next AI Network) 사전과제는 본선에서 에이전트 설계·디렉팅 명세로 확장될 것을 전제합니다.  
따라서 사전과제 단계에서 증명해야 할 것은 다음 세 가지입니다.

1. **플레이 가능** — 심사자가 즉시 실행해 전투·성장·보스를 경험할 수 있을 것  
2. **연출 시스템** — Director의 Phase / Memory / Budget / Why가 UI로 보일 것  
3. **확장 가능성** — Observe→Decide→Act→Explain 루프가 본선 문서로 이어질 것  

초기에는 격자 미로 데모로 시작했으나, “연출을 보여주기엔 장르 설득력이 약하다”고 판단해 **탑다운 슈팅 로그라이크**로 재설계했습니다.

## 3. 벤치마크 → 이식

스팀 인기작에서 “왜 재미있는가”만 추출해 이식했습니다. (상세: `STEAM_POPULAR_BENCHMARK.md`)

| 작품 | 가져온 것 | Director Loop에서의 형태 |

| Diablo/PoE | 파워 판타지 가독성 | 빌드라인·세트 해금 배너 |

## 4. 코어 루프

```
이동 · 사격 · 대시 · (차지샷) · Q 액티브
  → 적 처치 (XP)
  → 레벨업 시 카드 3택1 (Skip 가능)
  → 방 클리어 → 보상 / 포탈
  → R4에서 Safe vs Elite 분기
  → R7 보스 페이즈 1~3
  → Run Report (Style / Phase / 개입 사유 / 팁)
```

한 런은 고정 7방 구조로, 소량 랜덤(스폰·MOD)만 허용해 **심사 재현성**을 확보했습니다.

### 방 구성

| # | ID | 템플릿 | 의도 |
|---|-----|--------|------|
| 1 | R1 | Arena | 튜토리얼 / BUILD |
| 2 | R2 | Corridor | BUILD 압박 |
| 3 | R3 | Cover | SUSTAIN_PEAK |
| 4 | R4 | Fork | Safe(회복) vs Elite(Rare 확정) |
| 5 | R5 | Spikes | PEAK |
| 6 | R6 | Arena+Elite | 고위험 전투 |
| 7 | R7 | Boss | Phase 1→2→3 |

## 5. 플레이 방법

### 조작

| 입력 | 동작 |
|------|------|
| WASD / 방향키 | 이동 |
| SHIFT | 대시 (짧은 무적) |
| 마우스 | 조준 · 클릭/홀드 사격 |
| 마우스 홀드 후 해제 | **차지샷** (강타·관통) |
| Space | 사격 (보조) |
| Q | **액티브 스킬** (세트에 따라 변화) |

### Q 액티브 (세트별)

| 세트 | Q 이름 | 효과 |
|------|--------|------|
| (미해금) | Pulse | 근접 범위 피해 |
| Gunner | Barrage | 부채꼴 관통탄 |
| Survivor | Ward | 회복 + 짧은 무적/오버드라이브 |
| Director's Pupil | Call | budget 회복 + 힐 드롭 |

### 성장

- 적 처치 → XP → 레벨업 → 카드 3장 중 선택 (**Skip 가능**)
- Rare pity: 일반만 계속 나오면 Rare 확률 상승
- Elite 루트 클리어 시 Rare 확정 보상
- 세트 2태그 달성 시 보너스 (관통 / 슬로우장 / budget+)

### Room Modifier

방 입장 시 Director가 규칙 카드를 붙입니다.

| MOD | 플레이 체감 |
|-----|-------------|
| HASTE | 적이 빨라짐 |
| BRITTLE | 적은 약하지만 피격이 아픔 |
| RICH | XP 증가 |
| FOG | 시야 비네팅, 근거리 유리 |
| PRESSURE | Director budget 가속 (보스 등) |

## 6. 적·보스

| 타입 | 역할 |
|------|------|
| chaser | 예고 후 돌진 |
| ranged | 거리 유지 사격 |
| tank | 느린 근접 강타 |
| swarm | 저체력 다수 돌진 |
| sniper | 레이저 예고 후 고속탄 |
| elite | 산개 사격 + 기동 |
| boss | P1 nova → P2 유도/돌진 → P3 광역+minion |

보스 HP 구간(100%→60%→30%)에서 페이즈가 전환되며, 배너·Why·HP바 `P1/P2/P3`로 표시됩니다.

## 7. AI Director가 화면에 보이는 방식

우측 패널은 “로그”가 아니라 **결정 근거**입니다.

| UI | 설명 |
|----|------|
| Phase 칩 | BUILD / SUSTAIN_PEAK / PEAK_FADE / RELAX |
| budget | 개입 자원 |
| Memory | 직전 방 No-Hit, 다수 피격, 스타일 전환 등 |
| Why | 이번 개입의 한 줄 사유 |
| Timeline | Phase 전환·Action 이력 |
| Run Report | Style 비중, Phase 체류, 핵심 개입 3개, 다음 팁 |

특히 **PEAK_FADE**에서는 spawn/elite를 막아 “호흡 구간”을 강제합니다.  
이는 L4D Director의 ‘피크 이후 이완’을 규칙으로 명시한 부분입니다.

## 8. 실행 방법

1. 저장소 clone 또는 ZIP 해제  
2. `game/플레이하기.bat` 실행  
   또는 `game/index.html`을 Chrome/Edge로 열기  
3. **런 시작** 클릭  
4. (선택) `game/index.html?demo=1` — 자동 플레이 데모  

별도 서버·설치·로그인 없음. 오프라인 로컬 파일로 동작합니다.

### 시연 영상

- 파일: `demo/NextDir_DirectorLoop_Demo.webm`  
- 생성: Playwright가 `?demo=1` 자동 플레이를 녹화  
- 신청서용: YouTube **공개/일부공개** 링크 제출

---

## 9. 차별점 요약 (심사 체크)

1. Director가 **왜** 개입했는지 Why로 설명된다.  
2. Phase에 **금지 규칙(PEAK_FADE)** 이 있다.  
3. 플레이어 선택(Fork/Skip/세트)이 Memory·보상과 연결된다.  
4. 보스·MOD·신규 적으로 7분 안에서도 전투 깊이가 있다.  
5. 웹 단일 폴더로 즉시 플레이 가능하다.

---

## 10. 본선 확장 방향 (예고)

사전과제의 Phase/Memory/Why 테이블을 그대로 확장합니다.

- 에이전트 설계서: Observe 스키마, Action ontology, Budget 경제  
- 디렉팅 명세서: Phase 그래프, 금지 규칙, Why 템플릿  
- Eval: 개입 빈도 상한, Phase dwell, 클리어율 계측 (`tools/playtest.mjs`)
