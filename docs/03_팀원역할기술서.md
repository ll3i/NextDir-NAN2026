## 1. 역할 요약

개인 참가로 아래를 모두 수행했습니다.

| 영역 | 담당 내용 |
|------|-----------|
| 기획 | 장르 재설계, 벤치마크, 코어 루프, 방 그래프 |
| AI Director | Phase/Memory/Budget/Why/MOD 설계·구현 |
| 전투 | 적 AI, 보스 페이즈, Q/차지샷, 손맛 |
| 툴링 | playtest, demo 녹화, PDF/ZIP 패키징 |
| 문서 | 소개서·AI기술서·시연 스크립트·제출 가이드 |

## 2. 공정 (Observe → Decide → Rebuild → Verify)

| 구간 | 기간 감각 | 주요 결정·산출 |
|------|-----------|----------------|
| Observe | 초반 | L4D/Spire/Elden/Hades/BG3 축소 벤치마크, 우수 해커톤 사례 조사 |
| Decide | 중반 | 격자 데모 폐기 → 탑다운 슈팅+Director UI 확정 |
| Rebuild | 중후반 | Why/Report, Fork, 보스 P1–P3, MOD, Q, swarm/sniper |
| Verify | 제출 직전 | playtest 클리어율, softlock 수정, GitHub·PDF·영상 정리 |

---

## 3. 개인 참가에서의 AI 협업 방식

- 사람과 에이전트가 **같은 루프 문서**를 공유하고, 결정은 사람이 승인  
- 에이전트는 구현·계측·문서 초안, 사람은 재미/심사 설득력/범위 통제  
- “AI가 전부 만듦”이 아니라 **연출 시스템을 설계·검증하는 데 AI를 도구로 사용**
